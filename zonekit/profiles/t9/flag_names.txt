# Surface type names, read as data (SurfaceTypes.h). Rows: kind|name|value
#   surface_mask   the bits of the material's surface-flags word that hold the surface type (an enum, not a bit set)
#   game           the game id the materials sidecar names for this profile (value unused)
#   surface        a surface type: the masked word equals value
# Cold War (T9): the word is the u32 at material +0x20 (the Black Ops 4 layout less the 8 bytes its header lacks before the techset pointer), decoded with
# the Black Ops 4 table. TESTED, not proven: on mp_apocalypse, 165 of 173 materials whose name is also a stock Black Ops III material agree with that
# material's surfaceType, and 26 of 26 with the Black Ops 4 export (docs/hydrax-port/p2-surface-decals.md). There are no render rows: the techset renderFlags
# (+0x10) read 0 for every Cold War material in a disk export (the techsets are stubs there), so no decal class is taken from them.
