# Modern Warfare Remastered techset names to Black Ops III material types, read as data by Games/H1/MaterialAdapter.cpp.
# Rows: rule|id|conditions|bo3 techset|alpha mode|label   (first match wins; conditions are joined by ';'; the techset field SKIP:<code> leaves the material out)
#
# The MWR techset name is a grammar (mwr-materials.md section 2.2, sampler sets agree with it on every family checked): tokens split at '_',
# `l`/`sm`/`lmpb` lit, `ndw` no depth write (decals and transparents), `aat` alpha test, `cltrans` colour-transparent (glass-like), `effect_*`/`particle_*` particles,
# `2d*` UI, `wc_sky_*` sky, `wc_tools_*`/`tools_*` tools, a prefix m_ mc_ mv_ ml_ wc_ for model and world. The MWR material has no `water`, `glass` or `foliage`
# techset family: glass is `cltrans` plus the glass surface bit (8), the sort key (material byte 9: 2 opaque, 7..0x1f decals, 0x35 effects, 0x3c UI) tells decals from lit.
#
# Conditions: prefix=<text> (the name starts with it), token=<text> (one of the '_' tokens), tokenprefix=<text>, has=<text> (anywhere in the name),
#   metal / nonmetal (the description's surface type is in the metal_surfaces set below AND a specular map exists), plain (no gloss and no occlusion map),
#   sort>N / sort<=N (the sort key; false when unread), surface=<BO3 surfaceType> (the description surface after the surface decode), spec / nospec (a specular map),
#   reveal (a reveal map r1.. or rp is bound), any.
# Alpha mode: opaque, cutout (the colour alpha is a test), blend (the colour alpha is the opacity), keep (the adapter default).
# Labels: tested = the family counts in section 2.2 (techset names over 21,222 materials); hypothesis = the BO3 side choice, not run in the Mod Tools.
